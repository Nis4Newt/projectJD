# 카드 대전 게임 - 기본 규칙 (초안)

## 카드
- 카드는 **공격력**과 **체력** 스탯을 가짐
- 카드는 각자 고유한 **특수 능력**을 가질 수 있음
- 능력 발동 트리거는 다양하게 확장 예정: 머지 시 / 사망 시 / 상시 패시브 등

## 덱 구성
- 플레이어는 카드 **3종**을 선택해 덱을 구성
- 카드별 장수는 **5~15장 사이**에서 자유롭게 설정 (예: 강한 카드는 적게, 약한 카드는 많게)
- 선택한 3종의 장수 합은 **30장 이하**면 됨 (정확히 30장일 필요는 없음)
  - 얇은 덱(합이 적음): 평균 파워는 높지만 카드 고갈 위험 ↑
  - 두꺼운 덱(합이 30에 근접): 자원은 풍부하지만 평균 파워는 낮음

## 핸드(손패)
- 핸드에는 최대 4장 보유 가능
- 턴당 손패에 있는 카드를 원하는 만큼 낼 수 있음 (최대 4장)
- 드로우는 손패가 4장 미만일 때, 4장이 되도록 채움

## 필드
- 필드는 내 필드 3칸 + 상대 필드 3칸, 총 6칸
- 각 필드 슬롯에는 번호가 있음

## 전투 진행 (매 턴)
1. 주사위를 굴려 **공격자 슬롯**과 **타겟 슬롯**을 각각 무작위로 선정 (6칸 전체 대상)
2. 판정
   - 공격자 슬롯에 카드가 없으면 → **턴 넘김**
   - 타겟 슬롯에 카드가 없으면 → 해당 필드의 **플레이어 본체가 데미지**를 입음
   - 공격자와 타겟이 **같은 카드(자기 자신)**이면 → 공격력이 **2배**로 적용
   - 카드끼리 붙으면 → 공격자와 타겟이 **서로 공격력만큼 쌍방 데미지**를 주고받음 (체력이 0 이하가 되면 사망)
3. 플레이어 체력이 0 이하로 떨어지면 **패배**

## 머지
- 손패에 있는 카드를 **자신 필드 위의 같은 종류 카드**에 낼 때만 머지 가능
- 필드에 놓인 카드끼리는 서로 머지되지 않음
- 머지되면 합쳐지는 카드의 공격력/체력을 흡수
- 카드의 특수 능력은 대부분 머지 시 발동 (트리거 종류는 확장 예정)

## 능력 대상 선정 규칙
- "무작위 친구"를 대상으로 하는 능력은, 발동시킨 카드 자기 자신은 대상에서 제외됨
- "능력의 대상이 되지 않음"(면역) 카드는 무작위 대상 선정 후보군에서 아예 제외됨

## 용어
- 카드 = **친구**
- 플레이어 = **모험가**

## 기타
- 드로우 차례에 덱이 모두 소진되었다면 체력 -1

아 그러고보니 A, C가 서로다른 위협이네,

일단 A는 B(내 필드의 슬롯이 2개이상 비어있을때)랑 묶고, C와 구분

A+B일때 동작 알고리즘
   1. 능력으로 상대 필드 정리 가능한지 체크
   2. 내 필드 슬롯 채우기
   3. 모험가 체력관리

C는 아래 순서로
   1. 상대 패에 모험가 직접 공격 카드가 2개 이상 존재하는지 확률 검사
      - 바로 필드에 배치 가능할지 체크
   2. 상대 필드에 모험가 직접 공격 카드가 존재하는지 체크
   3. 능력으로 상대 필드를 정리 가능할지 체크
   4. 모험가 체력관리
   5. 내 필드 슬롯 채우기









상대 필드에 존재하는 모험가 직접 공격이 가능한 상대 필드처리 -> 체력관리 -> 필드방어
