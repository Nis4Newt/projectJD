## 테이블 파싱 방식 수정

### 기존 방식
- 테이블 생성 시 TableBase를 상속받고, TableBase의 PopulateFromText에서 파싱
- 읽어온 데이터는 csv의 헤더를 값을 기준으로 TableDataBase를 상속받은 클래스에 같은 이름의 변수에 넣는 중
- 읽어들인 데이터를 가공해야 할때는 OnLoaded를 사용해 데이터를 가공중

### 기획 의도
- 에디터로 csv를 읽고 asset을 만들때, 필요한 방식으로 가공, 저장이 한번에 적용되도록

### 구현 아이데이션
- TableData : TableDataBase<>의 변수가 csv의 컬럼 내용과 완전히 같을 필요 없음
	- 필요에 따라 csv의 3개의 컬럼 값이 tabledata의 하나의 배열에 들어갈 수도 있음
- TableBase의 PopulateFromText이 아닌 각각의 테이블 클래스에서 각자의 방식으로 파싱
	- 파싱할때 읽어들인 rows를 순차적이 아닌 string값으로 해당 컬럼의 데이터를 가져오고, 필요한 방식으로 파싱하도록
	- 이 경우 테이블 클래스에서 파싱할때 파싱할 컬럼의 값을 하드코딩해줘야 하긴 함
- PopulateFromText 자체를 대체하는건 아니고 PopulateFromText 내부의 newRows.Add에 들어갈 data를 반환하는 함수를 만드는 것에 가까움

## 드로우 관련 기능 추가

### 풀 핸드 드로우
- 핸드가 가득 찬 상태(4장)에서 드로우 되는 상태
- 드로우한 카드가 파괴되고 핸드로 들어오지 않음

### 덱 소진 후 드로우
- 덱의 모든 카드를 드로우한 후, 드로우 할 때
- 덱에 친구카드가 없으니 드로우 되지않고, 모험가가 1의 피해를 입는다

# 모험가 메인메뉴에서 친구 선택/교체하는 기능 구현 계획 문서

## 개요
- 친구 탭 : 친구카드 목록
	- 친구카드의 목록 노출
	- 현재 모험가가 선택한 친구카드(3개) 덱 표시

## 구성
- 친구 카드 panel 
	- mask + vertical scroll view
	- 상단에 3개의 슬롯, 슬롯 위에는 선택한 친구 카드가 노출
	- 하단에 grid layout group 이 있고 자식으로 친구 카드 프리팹이 달리고, 초기화 할때 cardTable에서 데이터 하나씩 적용
- 친구 카드 프리팹
	- 클릭시 선택 panel이 클릭한 친구 카드 프리팹 위치에 오픈
		- 선택 panel은 이미 만들어져 있고, 친구카드 프리팹과 선택 버튼으로 구성됨
- 선택 panel
	- 선택 버튼 클릭시, 친구 카드 목록 오브젝트 hide
	- 교체 ui active
- 교체 ui
	- 안내 object와 드래그 친구카드로 구성
	- 선택 state인 상태
	- 교체 ui의 친구카드를 드래그하여 친구 카드 panel의 슬롯으로 drop하면 교체됨
	- 친구 카드 panel의 슬롯을 직접 클릭해도 교체됨
	- 친구 카드 panel을 누르면 다시 친구카드 목록이 뜨고, 교체 ui는 꺼짐, state도 바뀌면 될듯
	- 드래그 하다 슬롯 아닌데서 놓으면 다시 돌아감
