## 분석 대상

현재 변경점으로 생성되었거나 수정된 plan 문서

## 분석할 내용
- 실제 구현된 코드(클래스 구조, 파일 구성, 이벤트, 상태 전이 등)와 문서 내용이 일치하는지 확인하고, 다르면 코드 기준으로 문서를 반영
- 중복된 내용 제거
- 불필요한 내용 제거
- 문서가 수정되었을 경우 정확한 내용인지 확인
- 문서 내에는 히스토리는 포함시키지 않고, 변경된 내용이 있다면 현재 설계 상태만 반영
